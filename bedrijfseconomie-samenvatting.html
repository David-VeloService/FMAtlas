Module 1 — Basisprincipes

Investering

Investering Een grote uitgave aan iets wat je voor een langere periode gebruikt. Bedoeld om geld mee te verdienen, te besparen of te voorkomen dat je geld gaat verliezen.
Op het moment van investeren word je niet armer of rijker. Hetzelfde geldt voor lenen: op het moment van lenen word je niet armer of rijker.

Kosten vs. opbrengsten

Kosten Aan perioden toegerekende uitgaven. Kosten verlagen je winst.
Opbrengsten Aan perioden toegerekende ontvangsten. Opbrengsten verhogen je winst.

Module 2 — Financiële overzichten

De balans

Balans Overzicht van bezittingen en schulden op één bepaald moment. Debet (links) = activa. Credit (rechts) = passiva. Totaal debet = Totaal credit (altijd!).
DEBET (Activa)CREDIT (Passiva)
Vaste activaEigen vermogen
Vlottende activaVreemd vermogen lang
— VoorradenVreemd vermogen kort
— Debiteuren— Crediteuren
— Te vorderen BTW— Te betalen BTW
— Liquide middelen— Voorzieningen
EV = Bezittingen - Schulden. Activa worden altijd exclusief BTW op de balans gezet (behalve debiteuren en crediteuren: inclusief BTW).

Resultatenrekening — EBITDA naar EAT

Omzet (q × p, excl. BTW) − Inkoopwaarde omzet (IWO) = Brutowinst − Overige kosten = EBITDA // vóór rente, belasting, afschrijving − Afschrijvingen = EBIT // vóór rente en belasting − Rentekosten = EBT // vóór belasting − Vennootschapsbelasting (EBT × %) = EAT // nettowinst

Kasstroomoverzicht

Kasstroomoverzicht en liquiditeitsbegroting (terugkijken tegenover vooruitkijken) Overzicht van alle ontvangsten en uitgaven over een periode. Niet kosten/opbrengsten, maar daadwerkelijke geldstromen. Beginsaldo + ontvangsten - uitgaven = eindsaldo.
Factuurmoment ≠ betaalmoment. Ontvangen/verstuurde rekening = nog géén ontvangst/uitgave. Betaling = wel ontvangst/uitgave.

Module 3 — Kosten en geldstromen

Primaire vs. secundaire geldstromen

Primaire geldstroom

Geldstromen die direct samenhangen met productie en verkoop. Worden gebruikt bij investeringsbeoordelingen (BTP/NCW/ETP).

Secundaire geldstroom

Geldstromen die samenhangen met de vermogensmarkt: leningen, aflossingen, rentebetalingen, aandelenkapitaal, dividend.

Primaire geldstroom (voor investeringsbeoordeling) = EAT + Rentekosten + Afschrijvingen // Afschrijving terug: is geen geldstroom (boekhoudkundig). // Rente terug: hoort bij financiering (secundair), // niet bij het project zelf — zo blijft de beoordeling // onafhankelijk van hoe het project gefinancierd wordt.

BTW (omzetbelasting)

Factuurstelsel BTW boeken op het moment van factuur (niet betaling). Inkoop-BTW terugvragen (te vorderen BTW, debet). Verkoop-BTW afdragen (te betalen BTW, credit).
Excl. BTW → Incl. BTW: bedrag × 1,21 Incl. BTW → Excl. BTW: bedrag / 1,21 BTW-bedrag (21%): excl. × 0,21 BTW-bedrag (9%): excl. × 0,09
Activa en kosten staan altijd EXCLUSIEF BTW op de balans/resultatenrekening. Debiteuren en crediteuren staan INCLUSIEF BTW.

Afschrijving

Afschrijving per jaar = (Aanschafwaarde − Restwaarde) / Aantal jaren

Module 4 — Managen en calculatie

Break-even analyse

TO = q × p // totale opbrengst TK = (q × v) + C // totale kosten Break-even: TO = TK Dekkingsbijdrage = p − v BEA = C / (p − v) // break-even afzet, altijd ↑ afronden BEO = BEA × p // break-even omzet (1 product) Veiligheidsmarge (€) = Werkelijke omzet − BEO Veiligheidsmarge (%) = VM / WO × 100%

Kostprijsberekeningen

// Integrale kostprijs (per eenheid) IK = (C / N) + (V / W) // C/N = constante kosten gedeeld door normaal aantal eenheden // V/W = variabele kosten gedeeld door werkelijk aantal eenheden // Beide termen zijn dus al per-eenheid voordat je optelt. // Enkelvoudige opslagmethode Opslag% = Totale indirecte kosten / Totale directe kosten × 100% Kostprijs = DC + (DC × Opslag%) // Nooit opslagpercentage afronden! // Forfaitaire calculatie Kostprijs = directe kosten + vast bedrag of vast % indirecte kosten // Geen verfijnde verdeling: één forfait dekt alle indirecte kosten. // Snel en simpel, maar minder precies dan opslag- of integrale methode.

Personeelskosten en uurtarief

Productieve uren berekening

1Contracturen = uren per week × 52
2− Vakantiedagen (dagen × uren/dag)
3− Ziekteverzuim (% van overgebleven uren)
4− Pauze (dagen/week × 52 × pauze-uren/dag)
5− Leegloop (% van overgebleven uren) = Productieve uren
Werkgeverslasten = Brutoloon + vakantiegeld + sociale lasten + overig Kostprijs/uur = Werkgeverslasten / Productieve uren Uurtarief = Kostprijs × (1 + overhead%) × (1 + winst%) × (1 + BTW%)

Differentiële calculatie

Differentieel resultaat Extra opbrengsten − extra kosten door de opdracht. Constante kosten zijn al gedekt en worden NIET meegenomen. Sunk costs worden NIET meegenomen.

Module 5 — Financiële kengetallen

Solvabiliteit (lange termijn)

Wat? Kan het bedrijf op lange termijn aan zijn financiële verplichtingen voldoen? Interessant voor: directie, leveranciers, banken.
Solvabiliteits% = EV / TV × 100% Debt ratio = VV / TV // TV = EV + VV // Gebruik 1 moment, GEEN gemiddelden!

Liquiditeit (korte termijn)

Wat? Kan het bedrijf op korte termijn zijn rekeningen betalen? Interessant voor: directie, leveranciers, banken.
NWK = Vlottende activa − Kort VV CR = Vlottende activa / Kort VV QR = (Vlottende activa − Voorraden) / Kort VV // Gebruik 1 moment, GEEN gemiddelden! // Voorzieningen = GEEN Kort VV

Rentabiliteit

Wat? Hoeveel rendement behaalt het bedrijf? Gebruik WEL gemiddelden (begin- + eindbalans / 2).
REV = EAT / Gem. EV × 100% RTV = EBIT / Gem. TV × 100% KVV = Rente / Gem. VV × 100% // Gemiddeld VV = (VV begin + VV eind) / 2

Module 6 — Investering beoordelen

DPG en BTP

DPG — Differentiële Primaire Geldstromen Alleen de primaire geldstromen die veranderen door jouw investering.
BTP = optellen DPG's per jaar totdat investering overschreden BTP maanden = (Benodigd bedrag in jaar / Jaarbedrag) × 12 // Altijd naar BOVEN afronden // BTP houdt GEEN rekening met tijdswaarde van geld

Tijdswaarde van geld

Geld dat je eerder krijgt is meer waard dan geld dat je later krijgt — omdat je er meer geld van kan maken. Uitgaven zo laat mogelijk, ontvangsten zo vroeg mogelijk.
Toekomstige waarde (TW) = Waarde nu × (1 + r)^n Contante waarde (CW) = TW / (1 + r)^n // r = rente/vermogenskostenvoet, n = aantal jaren

NCW en ETP

NCW = Som van alle contante DPG's − Investering CW jaar 1 = DPG jaar 1 / (1 + r)^1 CW jaar 2 = DPG jaar 2 / (1 + r)^2 ... NCW > 0 → Investering is rendabel ✓ NCW < 0 → Investering haalt rendement niet ✗
ETP — Economische Terugverdienperiode Zelfde als BTP maar dan met contant gemaakte DPG's. Houdt WEL rekening met tijdswaarde van geld. Verschil: ETP ≥ BTP (want contante waarden zijn lager).
MethodeTijdswaarde?
BTPNee — gebruikt gewone DPG's
ETPJa — gebruikt contante DPG's
NCWJa — vergelijkt contante waarden

Module 7 — FM-economie: TCO en NEN 2748

Total Cost of Ownership (TCO)

TCO Alle kosten die een product of dienst gedurende zijn hele levensduur veroorzaakt — niet alleen de aankoopprijs. Vooral relevant bij FM-investeringen (gebouwen, installaties, wagenpark, ICT, koffieautomaten).

Drie kostenfasen:

  • Pre-transactie — selectie, marktonderzoek, specificeren, aanbesteden
  • Transactie — aanschaf, installatie, training
  • Post-transactie — gebruik, energie, onderhoud, reparatie, verzekering, afvoer
TCO = Aanschafkosten + Som(jaarlijkse exploitatiekosten × levensduur) + Onderhouds- en reparatiekosten + Eindafvoerkosten − Restwaarde
De goedkoopste optie bij aankoop is vaak de duurste over de levensduur. TCO maakt dat verschil zichtbaar en is daarmee een betere basis dan kale offertevergelijking.
